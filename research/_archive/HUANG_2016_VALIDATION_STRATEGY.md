## §1 ε 与 k₁ 的物理含义

### 基本定义

论文引入表面张力修正项 **Q_m**（Eq. 57–59），通过两个旋钮 k₁、k₂ 调节表面张力：

```
ε = −8(k₁ + k₂)                                  (定义)
σ ∝ (1 − 6k₁)                                     (Eq. 62, 当 k₂ = 0 时)
σ ∝ (1 + ¾ε)                                       (用 ε 表达的等价形式)
```

### ε 调节什么？—— 无量纲表面张力系数

ε 是一个**无量纲表面张力尺度参数**：

| ε 值 | k₁ (k₂=0) | 1−6k₁ | 表面张力 | 物理含义 |
|------|-----------|-------|---------|---------|
| 0 | 0 | 1.0 | σ_max | 基准 MRT（无 Q_m 修正）|
| −2/3 | +1/12 ≈ 0.083 | 0.5 | σ_max/2 | 你当前的默认值 |
| −4/3 | +1/6 | 0 | 0 | σ→0，界面消失 |
| +1 | −1/8 | 1.75 | 1.75×σ_max | 论文 Fig. 5a 的 ε=1 组 |
| +2 | −1/4 | 2.5 | 2.5×σ_max | 论文 Fig. 5b 的 ε=2 组 |

- **ε > 0**: 增强表面张力（k₁ 为负，Q_m 项加回到碰撞）
- **ε = 0**: 基准 MRT 表面张力（无 Q_m 修正）
- **ε < 0**: 减弱表面张力（k₁ 为正，Q_m 项抵消部分应力）
- **ε 的有效范围**: (−4/3, +∞)，对应 k₁ ∈ (−∞, 1/6)

### k₁ 调节什么？—— 底层矩空间修正参数

k₁ 是**真正进入内核的参数**，它修改 Q_m（矩空间修正项）的幅值：

```cuda
// compute_Q_huang_gpu 中
double Qm1 = 3.0 * (k1 + 2.0 * k2) * F² / (|G|·ψ²·c²);
double Qm7 = k1 * (Fx² − Fy²) / (|G|·ψ²·c²);
double Qm8 = k1 * Fx·Fy / (|G|·ψ²·c²);
```

Q_m 随后被烘焙进碰撞项：

```cuda
// mrt_collide_single_component_gpu 中
mout_m = mk − s_k·(mk − meq_k) + (1 − 0.5·s_k)·S_k·δt + C_k·δt
                                         ↑ force term    ↑ Q_m correction
```

**物理直觉**：k₁ 控制了各向异性应力张量修正（Eq. 55–56）的强度。正 k₁ 抵消界面应力，负 k₁ 增强界面应力。

### k₂ 调节什么？—— 二阶各向同性修正

k₂ 只进入 Q_m 的**各向同性分量**（slot 1/2 的 Q_m1 = 3(k₁+2k₂)·F²/denom），不进入各向异性分量（slot 7/8 只含 k₁）。

论文用 k₁ ≠ 0, k₂ = 0 与 k₁ = 0, k₂ ≠ 0 的对比来验证 **σ 只取决于 k₁，与 k₂ 无关** —— 这是论文的核心声称。

## §2 论文的验证方案总览

论文设计了 **三套验证**（Fig. 3–5），分别验证共存曲线、表面张力线性关系、以及 σ-decoupling。

### 验证 1: 共存曲线（Fig. 4）

| 项目 | 值 |
|------|-----|
| 几何 | 平界面（flat interface），`huang_init_mode=2` |
| 网格 | 1024×8（论文）或 256×256（可替代） |
| 扫描参数 | Tr ∈ [0.6, 0.95]（即 cs_T 扫 6-8 个值） |
| 固定参数 | ε=1 或 ε=2，τ=1.5 |
| 提取量 | ρ_l, ρ_g（平界面平台值） |
| 对照 | (1) Maxwell 等面积构建 (2) 解析压力张量 Eq.(61) (3) LBM 数值结果 |
| 论文图 | Fig. 4(a) ε=1, Fig. 4(b) ε=2 |

**验证目标**：三条线重合 → EOS + 力学稳定性 + 数值方法三者自洽。

### 验证 2: σ-decoupling —— 核心声称（Fig. 5）

| 项目 | 值 |
|------|-----|
| 几何 | 静态液滴（droplet），`huang_init_mode=1` |
| 网格 | 256×256 |
| R | r₀ = 64δx（即 huang_R0 = 64） |
| 固定参数 | τ=1.5, Tr=0.9（cs_T=0.9） |
| 扫描参数 | **三组** (k₁, k₂) 组合，每组满足同一 ε |

#### ε = 1 组（Fig. 5a）

| 编号 | k₁ | k₂ | 1−6k₁ | 说明 |
|------|-----|-----|--------|------|
| 1 | 0 | −1/8 | 1.0 | 纯 k₂ 贡献 ε |
| 2 | −1/16 | −1/16 | 1.375 | 混合贡献 |
| 3 | −1/8 | 0 | 1.75 | 纯 k₁ 贡献（你当前只支持）|

#### ε = 2 组（Fig. 5b）

| 编号 | k₁ | k₂ | 1−6k₁ | 说明 |
|------|-----|-----|--------|------|
| 1 | 0 | −1/4 | 1.0 | 纯 k₂ 贡献 ε |
| 2 | −1/8 | −1/8 | 1.75 | 混合贡献 |
| 3 | −1/4 | 0 | 2.5 | 纯 k₁ 贡献 |

**验证目标**：σ vs (1−6k₁) 是一条**通用直线**，与 ε 无关，与 k₂ 无关。

### 验证 3: Laplace 定律（Fig. 5 内嵌）

同一张 Fig. 5 的多色散点：对每种 (k₁, k₂) 组合，跑多组 R 值（R=30, 40, 50, 60, 70...），验证 δp ∝ 1/R。

### Step 1: 实现 k₂ 独立控制

当前代码 `push_device_constants` 中 `k2_computed` 硬编码为 0。要复现论文，需要让用户可通过 `params.txt` 或设计 CSV 设置 k₂：

**方案 A（推荐）**: 在 `RuntimeParams` 中添加 `k2_huang` 字段，使 k₁, k₂ 可独立设置：

```
epsilon_huang = -8*(k1 + k2)  ← 用户设此，自动算 k₁, k₂ 验证
```

但目前只设定了 `epsilon_huang` → k₁=−ε/8, k₂=0。要复现论文的 k₂≠0 情况，需要添加单独的 `k2_huang` 参数。

### Step 3: σ-decoupling（Fig. 5 主体）

1. 生成设计 CSV（以 ε=1 组为例）：

```python
# ε = 1 组: k₁+k₂ = −1/8
combos_eps1 = [
    (0.0, -0.125),      # k1=0, k2=-1/8
    (-0.0625, -0.0625), # k1=-1/16, k2=-1/16
    (-0.125, 0.0),      # k1=-1/8, k2=0
]
# ε = 2 组: k₁+k₂ = −1/4
combos_eps2 = [
    (0.0, -0.25),       # k1=0, k2=-1/4
    (-0.125, -0.125),   # k1=-1/8, k2=-1/8
    (-0.25, 0.0),       # k1=-1/4, k2=0
]

for k1, k2 in combos_eps1 + combos_eps2:
    cases.append({
        "case_name": f"decouple_k1{k1}_k2{k2}",
        "cs_T": 0.9,           # Tr=0.9
        "huang_R0": 64.0,      # r₀ = 64δx
        "epsilon_huang": -8*(k1 + k2),
        # "k2_huang": k2,       ← 需要添加此字段
        "huang_rho_g": rg, "huang_rho_l": rl
    })
```

2. 运行 → 分析 σ vs (1−6k₁) 拟合。
