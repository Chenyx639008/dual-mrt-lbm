# 多孔介质水合物分解案例设计说明

本案例在真实多孔介质背景下验证三件事：

1. 热扩散驱动的水合物分解前沿能否从热源侧（右边界）向冷区（左侧）推进
2. 两种水合物赋存形态（包覆膜型 / 孔隙填充型）的分解行为差异
3. 潜热吸热对分解速率的局部抑制效应是否可被空间温度场观测到

---

## 1. 域与几何定义

### 1.1 网格（与 `LBM.h` 编译期常量对应）

```c
constexpr unsigned int NX  = 339 * SCALE;  // 原注释 "360"
constexpr unsigned int NY  = 212 * SCALE;  // 原注释 "240"
```

> **修改 NX/NY 必须重新编译**。运行脚本中的 `DOMAIN_NX=339` 和 `DOMAIN_NY=212` 仅用于生成参数文件注记，实际格子数由编译期常量决定。

### 1.2 多孔介质生成：`build_circle_array`

使用 `LBM.cu` 中的 `build_circle_array` 函数在旋转方形阵列上布置颗粒：

| 参数       | 符号         | 值  | 说明                           |
|------------|--------------|-----|--------------------------------|
| 固体颗粒半径 | `r_obs`      | 16  | 石英颗粒，flag=-2，mat=1       |
| 颗粒间隙    | `l_gap`      | 4   | 颗粒中心距 = 2×r_obs + l_gap  |
| 包覆膜厚   | `coat_thick` | 4   | 仅 morph=2 生效                |
| 填充球半径  | `r_mid`      | 8   | 仅 morph=1 生效；放在中点孔隙  |

### 1.3 两种形态

#### morph=2（包覆膜型 coating）

水合物以薄膜形式包裹在固体颗粒外表面，厚度 4 格。
节点类型：颗粒内核 flag=-2（石英），外壳 flag=-3（水合物），界面 ghost flag=-1/mat=2。

#### morph=1（孔隙填充型 pore-fill）

水合物独立占据颗粒间孔隙，以球形形式位于相邻颗粒中点，半径 8 格。
固体颗粒本身无水合物包裹。

## 2. 热边界与物理场景

### 2.1 参数（来自 `configs/hydrate_porous.yaml`）

| 参数           | 值        | 说明                                       |
|----------------|-----------|--------------------------------------------|
| `T0_init`      | 274.15 K  | 初始均匀温度（1 °C），水合物稳定           |
| `T0_inlet`     | 298.15 K  | 右边界固定温度（25 °C），触发分解          |
| `thermal_bc_side` | 3      | 右边界（x=NX-1）Dirichlet，左边界全展开  |
| `hydrate_start_step` | 0   | 从 flow 阶段第 0 步即激活水合物物理        |

### 2.2 边界条件示意

```
x=0 (左)                              x=NX-1 (右)
绝热全展开                             T = T0_inlet = 298.15 K
←──────────────── 热扩散方向 ──────────────────────
      温度梯度从右向左建立
      分解前沿从右向左推进 →
```

- y=0（底边）和 y=NY-1（顶边）：周期性复制（D2Q5 stream 自然周期）或全展开，不施加 Dirichlet。

### 2.3 物理时序

```
阶段 1：eq（相分离，无驱动，无水合物物理）
  → 水和气相分离，建立毛管平衡
  → 默认 eq_max_steps=100000 步，收敛即停

阶段 2：flow+hydrate
  Step 0：T 均匀 = 274.15 K，水合物完全稳定，diss_rate ≈ 0
  Step ~1000+：右边界热量扩散进入计算域，右侧 T 开始升高
  Step ~N：右侧水合物 T 超过临界值，diss_rate > 0，Vh 开始下降
  Step ~N+..：VOP 翻转开始，右侧水合物节点转为流体
  最终：整个计算域温度升至接近 298.15 K，全部水合物分解
```

```bash
  --morph coating \
  --inlet-temp 310.0 \
  --flow-max-steps 1000000 \
  --output-every 10000
```

## 5. 结果检查清单

跑完后，按以下顺序检验物理一致性：

### 5.1 温度场（`T` 在 flow VTK 中）

- [ ] `step=0` 时 T 全域均匀 ≈ 274.15 K
- [ ] 随时间步增大，右侧 T 先升高，梯度向左推进
- [ ] 固体颗粒附近 T 连续（共轭热传递，通过 MRT 弛豫实现）
- [ ] 水合物分解区域可见轻微 T 凹陷（潜热吸热）

### 5.2 分解速率场（`diss_rate`）

- [ ] 初始几步 `diss_rate ≈ 0`（温度不足，速率极低）
- [ ] 随右侧 T 升高，`diss_rate` 从右边界水合物节点开始出现
- [ ] coating 形态：沿颗粒外壳均匀分布；porefill 形态：填充球外缘出现

### 5.3 体积分数（`Vh`）

- [ ] 初始 `Vh = 1.0` 全域
- [ ] 右侧水合物节点 `Vh` 先下降
- [ ] VOP 翻转后该节点 `Vh = 0`，`pointsflag` 变为流体（`flag = 1`）

### 5.4 浓度场（`Cm`）

- [ ] 分解区附近 `Cm` 升高（甲烷释放）
- [ ] 气泡（rho_B 富集区）在分解位置形成

## 6. 新增 `thermal_bc_side` 参数说明

`thermal_bc_side` 控制热场 Dirichlet 边界在哪一侧施加：

| 值 | 热 Dirichlet 边 | 对面处理     | 适用场景          |
|----|-----------------|--------------|-------------------|
| 0  | 底边 y=0        | 顶边全展开   | 球形案例（原行为）|
| 1  | 顶边 y=NY-1     | 底边全展开   | 顶部加热          |
| 2  | 左边 x=0        | 右边全展开   | 左侧加热          |
| 3  | 右边 x=NX-1     | 左边全展开   | 多孔介质案例      |

**注意**：x 方向边界（side=2/3）在 y=0 和 y=NY-1 行采用周期/全展开处理，不受 thermal_bc_side 影响。

## 7. 诊断要点

- **分解未发生**：检查 `T0_inlet` 是否足以使 `Csat(T_nbr) < Cm_nbr`（即温度升高后溶解平衡浓度高于当前溶解浓度，才能产生正驱动力）。当前设置下 T 从 274.15 → 298.15 K，Arrhenius 因子约增大 `exp(-Ea/R*(1/274-1/298)) ≈ exp(3.4) ≈ 30` 倍，速率有明显变化。
- **前沿推进太慢**：热扩散时间尺度 `t_diff ~ L²/α ~ (0.0034 m)²/(1.4e-7 m²/s) ≈ 80 s`，对应格子步数 `80 / dt_phys = 8×10⁷`。若 flow_max_steps 只有 5×10⁵ 步，热前沿仅推进约 `sqrt(5e5*1e-6/8e-14) ≈ 2.5 mm`，即 ~25 格。需根据关注深度调整 flow_max_steps。
- **两种形态比较**：porefill 的接触面更集中（球状界面），速率空间分布比 coating（颗粒环形均匀分布）更局部化。
