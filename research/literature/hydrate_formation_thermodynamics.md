## 2. 双场表示：甲烷的两种存在形式（核心基础）

### 2.1 两个字段各代表什么

| 字段 | 代表 | 只在 | 物理意义 |
|---|---|---|---|
| **`Cm[s]`** | **溶解在水里的甲烷**（D2Q5 扩散场） | 液体节点（flag≥0） | 水中可自由扩散的甲烷，参与碰撞/流步 |
| **`Vh[s]`** | **水合物固体的体积分数**（标量场） | 水合物节点（-3 及 mat=2 ghost） | 晶体里锁住的甲烷 = **`Vh × Cm_per_Vh`** |

**关键**：`Cm` 是会**扩散、流步**的场；固体水合物内部**没有水**，所以"溶解在水里的甲烷浓度"在固体里**按定义就是 0**（`kernel_update_Cm` 对 flag<0 强制 `Cm=0`）。水合物锁住的甲烷**不能**放在 `Cm` 里（否则会跟着扩散跑出去），只能放在 `Vh×Cm_per_Vh` 这个"固体储层"里。

### 2.2 "Cm=0"与"存储甲烷"不矛盾（同一事实的两面）

```
一个流体节点长成水合物：

  流体节点              生长中                  翻成水合物(-3)
  Cm = 3.5     →    Cm 下降、Vh 上升     →    Cm = 0（无水的溶解态）
  Vh = 0             Vh: 0→1                    Vh = 1（晶体储层）
  甲烷 = 3.5+0      甲烷 = Cm + 100·Vh          甲烷 = 0 + 100·1 = 100
```

- **`Cm=0`**：甲烷不再以**溶解态**存在（变成晶体了）。
- **`Vh×100`**：甲烷转移到了**储层态**（锁在水合物晶体里）。
- 两者相加 = **L1 不变量**：$\sum C_m + C_mPerVh\sum V_h = \text{const}$。**第二项就是"水合物节点内部存储的甲烷"**。

### 2.3 守恒数值证据（物理速率案例 `rate_0.001` 实测）

| 时刻 | ΣCm（溶解态） | ΣVh（储层） | 总量 ΣCm+100·ΣVh |
|---|---|---|---|
| step 0 | 251464 | 21.0 | 253564 |
| step 3000 | 250633 | 29.3 | **253563**（漂移 -0.0003%） |

成核日志的 **"CH₄ 赤字 2026.50"** = $21\times(100-3.5)=2026.5$——即 21 个成核节点储层从"初始溶解 3.5"填到"晶体 100"，每个差 96.5，由**远处过饱和水（Cm=3.5）向生长前沿扩散补给**。溶解池掉 831，其中 830 进储层（ΣVh↑8.3×100），余 1 为出口边界物理扩散损失。

### 2.4 储层指标：Cm_per_Vh 的物理推导

$$
\Delta V_h\cdot\frac{V_{cell}}{V_m^{(p)}} = \Delta N_{CH_4}\quad\Rightarrow\quad \Delta C_m^{(l)} = \Delta V_h\cdot\frac{1}{C_{scale}V_m^{(p)}} = \Delta V_h\cdot C_mPerVh
$$

- $V_m^{(p)} = 1.3\times10^{-4}\,\text{m³/mol}$（修正后水合物摩尔体积）
- $C_{scale} = 76.75\,\text{mol/m³}$（= Tishchenko 2005 在 278 K/10 MPa 的溶解度 0.0768 mol/kg）
- **$C_mPerVh = 1/(C_{scale}V_m) = 100.2 ≈ 100$**（格子单位；Phase 0 核实）

> 含义：每积累 1 单位体积分数 $V_h$，水合物内存储相当于 **100 单位格子浓度**的 CH₄。

## 3. 液固边界：谁在消耗甲烷？ghost 的角色？

### 3.1 直接回答：消耗发生在"生长前沿的流体节点"，不是 ghost

```
水合物内部(-3) │ ghost(-1, mat=2) 已形成水合物 │ 边界流体(flag=0) ← 生长 Vh + 消耗 Cm │ 远处流体(flag=1)
   Vh=1, Cm=0       反应速率在此评估             Vh: 0→0.99, Cm 被抽走                        Cm=3.5 过饱和
   不消耗             不消耗(死值)                    ←—— 消耗的唯一位置 ——→
```

- **ghost**：已是水合物（`is_hydrate` 真、Vh 已满），$C_m$ 被 `kernel_update_Cm` 强制 0，**从不消耗甲烷**。
- **边界流体节点（flag=0/1，紧挨 ghost）**：**生长前沿**。`kernel_accumulate_form_vop` 在此累积 Vh（0→1）、消耗它自己的 $C_m$（`Cm -= ΔVh·Cm_per_Vh` + 缩放同步）。长满 0.99 后**翻转为水合物（-3）**，前沿向外推进。

消耗链：**水合物前沿向内长一格 ⇒ 正前方流体节点提供甲烷 ⇒ 该节点 Cm 下降（贴近 Csat）⇒ 长满翻成新水合物**。

### 3.2 ghost 的三角色（"反应边界"不是消耗）

| 角色 | 代码位置 | 作用 |
|---|---|---|
| ① **no-flux 反弹壁** | `kernel_stream_conc` | 流体 g_out 在 ghost 表面半步反弹，甲烷不进入固体被丢弃（输运守恒必需） |
| ② **表面反应速率的评估点** | `kernel_boundary_conc_reaction` | 用紧邻流体浓度算过饱和度，写 `form_rate[ghost] = k_f·sup/Csat` |
| ③ **死值占位** | `g_in[ghost]=w5·Csat` | no-flux 下不喂回流体，只是占位 |

**关键**：`form_rate` 写进 ghost ≠ ghost 消耗甲烷。真正把速率变成 Vh 增长、并从水中抽走甲烷的，是**紧挨着的流体节点**（`kernel_accumulate_form_vop` 读 ghost 的 form_rate 长自己的 Vh、扣自己的 Cm）。

### 3.3 ghost 材质筛选性（水合物 vs 石英）

代码严格区分材质——**只有"属于水合物的 ghost"能存/放甲烷**，石英 ghost 不能：

| 属性 | 水合物 ghost（mat=2） | 石英 ghost（mat=1） |
|---|---|---|
| Vh 存储 | `is_hydrate = (fl==-3) \|\| (fl==-1 && mat==2)` → **有 Vh、存甲烷** | Vh=0，**不存甲烷** |
| L1 不变量 | 计入 `100·ΣVh` | 不计入 |
| 边界反应 | Kang 反应（形成/分解） | 默认全反弹；仅 `enable_quartz_nuc` 且过饱和时才异质成核 |
| 释放/消耗 | 分解释放 ΔVh·100 到流体邻居 | 永不释放 |

### 3.4 双节点映射 vs 单节点自洽

| 模式 | 速率在哪算 | Vh 在哪长 | 甲烷在哪消耗 |
|---|---|---|---|
| **mode 1/2**（已有水合物面） | **ghost**（界面动力学） | 紧邻流体节点 | 紧邻流体节点 |
| **mode 3**（CNT 体相成核） | **流体节点自身**（`kernel_form_direct_concentration`） | 同一流体节点 | 同一流体节点 |

两种模式的**消耗位置都是流体节点**，差别仅在"速率在哪评估"：mode 1/2 用 ghost 代表**紧凑前锋的界面反应**；mode 3 用流体节点代表**孔隙中分散成核的体相反应**。当前实现无 bug，ghost 从未消耗；若追求统一可把 mode 1/2 的速率评估也移到流体节点（可选重构）。

## 4. 边界平衡浓度与梯度：软钉扎

### 4.1 物理理想（教科书图像）

```
远处流体 C_m = 3.5（过饱和，>Csat）
        │  ── 甲烷扩散流 ──▶
边界流体 C_m ≈ Csat(T,P)   ← 水合物存在态的平衡浓度（MethaneSolubility/Tishchenko）
        │
水合物面（ghost）          ← 在此消耗甲烷，生长
```

**已由 V2 实证**：`<C_m>_near(生长) ≪ <C_m>_far(远处)`（物理速率下 near 稳定贴近 Csat；dev 快速率下 near 被抽穿到 0.0415 < 1.0）——梯度真实存在，甲烷从过饱和远处扩散到水合物面被消耗，即**扩散受限生长**。

### 4.2 当前实现 = "软钉扎"（动力学 + 质量守恒），不是"硬钉扎"

- 不是"在边界流体节点强制 $C_m \equiv C_{sat}$ 的 Dirichlet"。
- 而是：动力学 form_rate $\propto (C_m^{nbr}-C_{sat})/C_{sat}$ 在水合物面评估 + 显式消耗 $\Delta C_m = \Delta V_h\cdot100$ 把边界流体 Cm 抽走 + no-flux 反弹保证输运零泄漏。
- 结果：边界 Cm 在 Csat 附近**往复振荡**（消耗抽低 → 扩散回填 → 再抽低）。

**⚠️ 与 dev 快速率振荡的直接关系**：当形成速率超过扩散补给（form_relax=0.1，比物理快 100 倍），边界 Cm 被**抽穿到远低于 Csat**（0.0415 ≪ 1.0）→ mode 2 动态边界看到欠饱和 → 分解 → 释放 → 再过饱和 → 再形成 = **形成↔分解振荡**。**物理速率（form_relax=0.001）下扩散跟得上，边界 Cm 稳定贴近 Csat**，生长稳定（速率扫描证实）。

## 5. 平衡终态：形成自限（用户概念）

**原则**：水合物的形成**不能无节制地吸干所有的溶解甲烷**。其**最终平衡形态**是：**水合物以外的所有流体节点**的甲烷浓度等于 **MethaneSolubility（Tishchenko 2005）"有水合物存在条件下的甲烷平衡浓度"** $C_{sat}(T,P)$——处处相等、无梯度、无过饱和度、生长停止。

**为什么必然如此（动力学自限）**：
- 形成速率 $\propto sup = C_m - C_{sat}$（`form_rate = k_f·sup/Csat`）。
- 当所有流体节点 $C_m = C_{sat}$ 时 $sup=0$，**驱动力消失 → 形成停止**。
- 水合物只把"超出 $C_{sat}$ 的过饱和量"转化为晶体；**绝不会抽到低于 $C_{sat}$**（否则反向变成分解驱动力）。

**终态图像**：

```
水合物（Vh=1, 储层=100） │ ghost（反应面） │ 全部流体节点 Cm = Csat(T,P)（约定A归一化=1.0）
                            sup=0 → 生长停止         无梯度、无驱动力
```

**与代码机制对应**：

| 代码机制 | 如何保证终态 |
|---|---|
| `form_rate ∝ sup = Cm−Csat` | sup→0 时生长自动停止，不会吸干到低于 Csat |
| L1 不变量 $\sum C_m + 100\sum V_h = const$ | 过饱和量守恒地转入储层；溶解相收敛到 Csat |
| 缩放同步 `g_in *= Cm_new/Cm_i` | 消耗不破坏扩散流，确保过饱和能从远处补给到前沿 |

**瞬态 vs 平衡态**：
- **瞬态**（生长中）：前沿附近 Cm 可瞬时低于 Csat（快速率下形成快于扩散补给）——dev 快速率边界欠饱和的来源、形成↔分解振荡的机制。
- **平衡终态**（充分长时间后）：扩散拉平，所有流体节点 $C_m \to C_{sat}$，水合物停止生长。物理速率下前沿浓度稳定贴近 Csat 正是该终态的实现路径。

## 6. 质量守恒的实现：缩放同步（消费同步精化）

### 6.1 问题：消费同步丢弃扩散通量

水合物在流体节点生长 $\Delta V_h$，需从 `g_in`（D2Q5 5 方向分布，Σ = Cm）中扣除 $\Delta C_m = \Delta V_h\cdot100$。两种扣除方式：

| 方式 | 代码 | 效果 |
|---|---|---|
| **全重置**（旧） | `g_in[k] = w5[k]·C_m_new` | Σ=新浓度 ✅，但**抹平各向同性**，方向通量（m1/m2 矩）归零 → 每步"重新平衡化"，**丢弃真实扩散流** → 质量漂移（mode1 1.86%、CNT 8.6%） |
| **缩放**（新） | `g_in[k] *= C_m_new/C_m_i` | Σ=新浓度 ✅，且**每方向按同一比例收缩**，通量形状保留 → 不制造伪流、不丢方向 → **质量精确** |

**缩放物理含义**：把节点的浓度分布整体按比例"收缩"，既扣掉消耗的甲烷，又不破坏正在发生的扩散流（保正性、保通量方向）。`ratio = Cm_new/Cm_i ∈ (0,1]`，`Cm_i ≤ 1e-30` 时 ratio=0（保护除零）。

### 6.2 结果

| 环节 | 旧（全重置） | 新（缩放） |
|---|---|---|
| mode 1 反应路径残留 | 1.86% | **0.18%**（10×） |
| CNT 生长（物理速率 0.001） | 8.6% | **-0.0003%**（~28000×） |
| 惰性球输运 | 0.00% | 0.00%（不变） |
| 分解释放 V5 | 12.76 | 12.76（不变） |

### 6.3 附带的发现：dev 快速率 NaN = 物理不稳定（非同步缺陷）

速率扫描（缩放同步）：

| form_relax | 生长倍率 | 结果 | 3000 步 L1 漂移 |
|---|---|---|---|
| 0.1 | 100× 物理 | **NaN @2000**（形成↔分解振荡） | — |
| 0.01 | 10× | ✅ 稳定 | **-0.023%** |
| 0.001 | **物理** | ✅ 稳定 | **-0.0003%** |

**结论**：NaN 是 dev 快速率超过扩散补给极限的**物理不稳定**（缩放同步的诚实性暴露了它；全重置只是用各向同性抹平掩盖）。物理速率下稳定且质量近完美。分解案例 (161,58) 的 NaN 为**既有 SC 两相脆弱性**（新旧二进制相同，与同步无关）。

## 9. 结论与下一步

### 9.1 核心结论

1. **双场表示**：`Cm`（溶解态，液体迁移）+ `Vh×Cm_per_Vh`（储层态，晶体锁存）；`Cm=0` 于固体 ≠ 存储丢失，存储由 L1 第二项记账。
2. **谁消耗**：生长前沿流体节点；ghost 三角色（反弹壁/速率评估/死值）不消耗；材质筛选严格（仅水合物存甲烷）。
3. **边界平衡**：边界流体软钉扎到 Csat 形成梯度（扩散受限生长）；物理速率下贴近 Csat。
4. **自限终态**：形成 $\propto sup$，终态 = 全部流体 $C_m = C_{sat}(T,P)$。
5. **质量守恒**：缩放同步实现近完美（mode 1 0.18%、CNT 物理速率 -0.0003%）。
