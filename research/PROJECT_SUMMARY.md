## 一、项目定位

**dual-mrt-lbm** 是一个面向科学计算的双轨 MRT-LBM 框架，用于模拟多相流与甲烷水合物分解。核心创新在于**双轨架构**：一条 CUDA C++17 生产轨做高性能仿真，一条 JAX Python 镜像轨做可微验证与 AI 迭代，Python 统一层连接两端。

```
┌──────────────────────────────────────────────────────┐
│               Python 统一调度层                       │
│       uv run lbm models/run/info/validate/build      │
├─────────────────────┬────────────────────────────────┤
│  CUDA 生产轨 (C++)   │    JAX 镜像轨 (Python)          │
│  ─────────────────   │    ────────────────────         │
│  MRT 碰撞            │    MRT + BGK 碰撞              │
│  Huang-Zhang 力      │    Huang-Zhang 三阶力          │
│  CS/PR EOS           │    CS/PR/RK/RKS/VdW 5种EOS    │
│  吸附力+接触角BC     │    吸附力 + ψ-ghost BC         │
│  水合物热-浓度-VOP   │    jax.grad 伴随梯度            │
│  多孔介质达西流      │    jax.vmap 批量扫描            │
│  sm_120 GPU 优化     │    shard_map 多GPU 域分解       │
└─────────────────────┴────────────────────────────────┘
```

**核心理念**: 不是"JAX 替代 CUDA"，而是"JAX 为 CUDA 提供安全网和金标准"。

### 通过双轨发现的隐藏 Bug

双轨最有价值的产出之一是**发现了自 Phase 3 以来一直存在的 streaming 方向错误**：

```python
# 错误 (Phase 3-5 未被发现):
jnp.roll(f, -C[k], axis)  # 粒子沿 c_k 反方向移动

# 正确 (Phase 6 修复):
jnp.roll(f, C[k], axis)   # 粒子沿 c_k 方向移动
```

此 bug 在单轨时代永远无法发现——CUDA 代码是正确的，JAX 有 bug 但没有交叉验证机制。双轨建立后，液滴模拟直接爆炸（密度 10³⁵），4 小时排查定位。现在有 8 个参数化测试永久防护。

## 三、技术方法

### 物理模型

| 模型 | 方法 | 状态 |
|------|------|:----:|
| SCMP 单组分两相 | Huang & Wu (2016) + CS-EOS + MRT | ✅ |
| MCMP 多组分 | Shan-Chen + PR-EOS + 理想气体 | ✅ |
| 水合物分解 | 热传导 + 浓度扩散 + VOP 固相更新 | ⏳ |
| 多孔介质 | 达西流 + 颗粒阵列几何 | ✅ |

### 关键公式

**Huang-Zhang 三阶力** = SC 一阶力 + Q_m 矩空间修正：

$$F = -G\psi\nabla\psi + \varepsilon \cdot Q_m,\quad Q_m \propto \frac{|F|^2}{G\psi^2 c^2}$$

通过 k₁ 参数独立调节表面张力：$\sigma \propto (1 - 6k_1)$，$k_1 = -\varepsilon/8$。

**MRT 碰撞**（矩空间）：

$$m' = m - s_k(m - m_k^{eq}) + (1 - 0.5s_k)S_{guo} + C_{q_m}$$

s_k 松弛速率：s_ρ=s_j=1.0, s_e=s_ε=s_p=1/τ, s_q=1/(0.5+Λ/(τ-0.5))。

**伴随梯度**（CUDA 做不到的）：

```python
from jax_lbm.adjoint import grad_mass_loss
d_loss_d_eps, d_loss_d_T = grad_mass_loss(1.7, 0.70)
# 精确梯度，jax.grad 穿透 200 步 lax.scan
```

## 四、项目意义

### 方法论创新

双轨架构的核心价值是**建立验证闭环**：JAX 沙盒快速迭代 → 金标准验证 → 翻译到 CUDA → CUDA 结果与 JAX 金标准对比。这个方法论本身可成为论文创新点。

### 工程价值

| 场景 | 之前 | 之后 |
|------|------|------|
| 改碰撞公式 | 改CUDA→编译→跑→看VTK→反复 | 改JAX→pytest(70s)→翻译 |
| 找最优参数 | 手动试，凭经验 | vmap 一键扫描 |
| 新人上手 | 读 CUDA 源码 + 猜参数 | `uv run lbm info <model>` |
| 代码审查 | 肉眼 diff CUDA 内核 | JAX 测试即文档 |

### 科研价值

- **可复现性**: 模型定义声明式，参数可追溯
- **敏感度分析**: 伴随梯度回答"ε 改 1% 液滴质量影响多大"
- **AI 闭环**: JAX 可微性为 AI agent 自动调参铺路
