### 1.2 诊断步骤（Systematic Debugging）

| 阶段 | 操作 | 发现 |
|------|------|------|
| **Phase 1** | 读取生成的 `cs_coexistence_reference.json` 数据 | 在 Tr≈0.873 处数据出现**灾难性跳跃**：ρ_g 从 0.18 突降到 0.04 |
| **Phase 1** | 追踪 p-ρ 等温线，对比 p=0 交点 | p=0 交点精确匹配求解器的"ρ_g, ρ_l"输出 → 求解器收敛到 peq=0 |
| **Phase 1** | 分析 spinodal 点与稳定分支 | CS-EOS 气体 spinodal ρ_gas_spin > ρc，求解器把不稳定区内交点当气液共存 |
| **Phase 2** | 手工扫描正确 peq 区间 | 真解在 peq≈0.0004，ρ_g≈0.005，ρ_l≈0.357；旧解 peq=0，ρ_g=0.10 |

### 1.3 根因

**Bug 1 (致命)**：`delta_mu()` 不对交点按稳定分支分类
- p(ρ) 曲线与水平线 y=peq 有 3 个交点：气体（稳定）、不稳定中间态、液体（稳定）
- 旧代码取 `crossings[0]` 和 `crossings[-1]` 作为 ρ_g, ρ_l
- peq=0 时，"气体"交点恰好在不稳定分支内，密度 ρ_g=0.10 > ρc=0.033

**Bug 2**：peq bracket 包含无效区域
- 气体稳定分支仅在 peq > 0 时有交点（p→0 当 ρ→0）
- 旧 bracket `[p_liq_spin, p_gas_spin]` 在低温时下限为负
- Brent 求解器在包含 0 的区间内优先收敛到 peq=0

**Bug 3**：bracket margin 破坏窄区间
- 旧代码 `p_lo += margin; p_hi -= margin` 在低温时（peq ∈ [0, 8.7e-4]）挤压掉有效搜索空间

## 二、修复方案

### 2.1 `lbm_mrt/validation/cs_eos.py` — Maxwell 求解器重写

**核心改动**：

```python
# ① 识别 spinodal 点（稳定分支边界）
rho_gas_spin = rhos[idx_gas_spin]    # 气体分支上限
rho_liq_spin = rhos[idx_liq_spin]    # 液体分支下限

# ② 正确 peq bracket
p_lo = max(p_liq_spin, 1e-15)        # 气体分支仅在 p>0 存在
p_hi = p_gas_spin                     # 气体分支上限

# ③ delta_mu 按稳定分支过滤交点
gas_cross = [r for r in all_crossings if r < rho_gas_spin]   # 稳定气体
liq_cross = [r for r in all_crossings if r > rho_liq_spin]   # 稳定液体
if not gas_cross or not liq_cross:
    return None  # peq 无效，拒绝
rg = gas_cross[-1]   # 气体分支最右交点
rl = liq_cross[0]    # 液体分支最左交点
```

**其他改进**：
- 网格从 6000 → 20000 点，增强低密度区（ρ_g 可小至 1e-3）的分辨率
- 扫描采用 log+linear 混合策略（宽区间时自适应）
- Brent 容差收紧至 xtol=1e-14, rtol=1e-12

### 3.2 CS-EOS 非对称性说明

Tr > 0.86 时 ρ_g > ρc（例如 Tr=0.90: ρ_g=0.045 > ρc=0.033）。这是 CS-EOS 的**固有不 
对称性**：气体 spinodal 在所有亚临界温度下都位于 ρ > ρc。在高温段，Maxwell 构造给出 
的气体密度可略高于临界密度。这并非 Bug，而是该 EOS 模型的热力学特征。

### 5.2 中期 (三维扩展)

Huang & Wu (2016) 的 MRT 方法具有以下三维扩展优势：

| 特性 | 二维 (当前) | 三维 (计划) |
|------|------------|------------|
| 速度模型 | D2Q9 | **D3Q19** (或 D3Q27) |
| 矩空间 | 9 矩 | **19 矩** (需重新推导正交基) |
| 松弛矩阵 Λ | diag(1, s_e, s_ε, 1, s_q, 1, s_q, s_ν, s_ν) | **19 对角元素** |
| Q_m 项 | 3 个独立分量 (Qm1, Qm7, Qm8) | **6 个独立分量** (3D 应力张量) |
| σ 控制 | k₁ 标量 | k₁ 标量 (各向同性假设) 或 **k₁ 张量** (各向异性) |
| CS-EOS | 不变 | **不变** (EOS 与维度无关) |
| 网格 | 256² | **128³ ∼ 256³** (视 GPU 显存) |

**关键挑战**：
- D3Q19/D3Q27 的 MRT 正交变换矩阵需要重新推导（文献已有标准形式）
- Q_m 公式从 Eq. 59-62 推广到 3D（应力张量的各向异性部分增加 3 个分量）
- 显存需求：256³ × (19 分布函数 × 8 bytes) ≈ 2.5 GB，可行
- 性能：3D MRT 碰撞计算量约为 2D 的 3-5 倍

**稳定性优势**：
- Huang 的 Q_m 方案将 σ 控制与 EOS 完全解耦，3D 中同样成立
- MRT 多弛豫时间天然压制 3D 中更严重的 spurious currents
- CS-EOS 在 3D 中保持相同的热力学一致性
