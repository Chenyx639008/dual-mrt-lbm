## §3 🔴 核心突破：MRT-LB AC 液滴溶解根因定位（2026-08-08）

### 3.1 根因（已数值验证，确定性结论）

**不是反扩散源无效，而是平衡矩 m_eq 的矩序完全错乱。**

用 `jax_lbm/collision.py` 的 Lallemand D2Q9 变换矩阵（矩序 `[ρ, e, ε, jx, qx, jy, qy, pxx, pxy]`）验证：

- **正确**（Liang 2018 一阶平衡 f_eq=ω_iφ(1+c_i·u/c_s²) 经 M 变换）：
  `m_eq = [φ, −2φ, φ, φu_x, −φu_x, φu_y, −φu_y, 0, 0]`
- **旧实现**（6 个矩错误）：`[φ, φ, 0, φu_x, 0, φu_y, 0, φu_x/3, φu_y/3]`
  - e 矩：−2φ → 错用 φ；ε 矩：φ → 错用 0；qx：−φu_x → 错用 0；qy：−φu_y → 错用 0；pxx/pxy：0 → 错用 φu_x/3, φu_y/3

→ f_eq = M⁻¹m_eq 不是正确的平衡分布 → 恢复的 AC 方程错误 → 扩散-反扩散失衡 → 界面扩散 → 液滴溶解。

### 3.2 文献精确公式（已逐项数值验证 ✅）

**BGK-LB 保守 AC（Liang 2018 式 8-12，D2Q9 母本）**：
- 演化：f_i(x+c_iδ_t, t+δ_t) − f_i = −(1/τ_f)(f_i−f_i^eq) + δ_t F_i
- 平衡（**只到一阶**）：f_i^eq = ω_i φ (1 + c_i·u/c_s²)
- 源项（**必须含 ∂_t(φu)**）：F_i = (1−1/(2τ_f))·ω_i c_i·[∂_t(φu) + c_s²λn]/c_s²，λ=4φ(1−φ)/W
- 迁移率：M = c_s²(τ_f−0.5) → τ_f = M/c_s² + 0.5

**MRT-LB 保守 AC（Yang S11，2D 降维）**：
- 平衡矩：m_eq = [φ, −2φ, φ, φu_x, −φu_x, φu_y, −φu_y, 0, 0]
- 源项：R = [0,0,0,g_x,−g_x,g_y,−g_y,0,0]，g = ∂_t(φu) + c_s²λn（零阶矩=0 保质量守恒）
- 松弛：Λ_φ = diag(1,1,1,ω_φ,1,ω_φ,1,1,1)（只有 jx/jy 松弛）
- 迁移率：M = c_s²(1/ω_φ − 1/2)
- **MRT↔BGK 等价已验证**：ω_φ=1/τ_f 时 (I−Λ/2)R 动量矩 = (1−1/2τ_f)g
