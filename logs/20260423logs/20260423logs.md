      subpackages, YAML config, a build.py entry point, CLI commands, and tests.

     def fmt_value(v: Any) -> str:

     10-sig-fig."""

     def write_params_txt(params: dict[str, Any], path: str | os.PathLike) -> 
     None:
         """Write flat params dict to key-value params.txt format."""

     Behavioral note: The batch runner (run_batch_from_geometry.py) currently
     takes CSV row columns directly and writes only PARAM_KEYS + checkpoint
     defaults. The new params_writer.py writes all keys from the flat dict,
     which is a superset. The CUDA binary's load_params_txt() ignores unknown
     keys, so this is safe.

     lbm_mrt/solver/build.py

          [src/hydrate.cu src/hydrate_vop.cu]

      via lbm-build entry point with --hydrate, --arch, --debug flags.
