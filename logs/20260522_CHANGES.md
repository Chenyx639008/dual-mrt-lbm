## §2 今日改动

### 2.1 关键 Bug 修复：`compute_Q_huang_gpu` 中 G 符号错误

**文件**: `lbm_mrt/solver/src/LBM.cu`

**问题**: `compute_Q_huang_gpu` 核函数中，Q_m 分母使用了 `fabs(cs_G_loc)`:
```c
double denom = fabs(cs_G_loc) * psi2 * c_gpu * c_gpu;
```
其中 `cs_G_loc = -1.0`，`fabs(-1.0) = 1.0`。论文 Eq.(57-59) 中 Q_m 分母为 `|G|`，但代码中其他相关项（压力张量 `inv_Gpsi2 = 1.0/(G*psi2)`、宏观压力 `p = ρcs² + ½c²·G·ψ²`）均使用带符号的 `G`。`fabs` 导致 Q_m 的符号与压力张量修正不一致，破坏了平板界面的力学稳定性。

**修复** (由用户发现):
```c
// 修复前
double denom = fabs(cs_G_loc) * psi2 * c_gpu * c_gpu;
denom = fmax(denom, 1e-12);

// 修复后 — 保留 G 的符号，仅对绝对值做下限截断
double denom = cs_G_loc * psi2 * c_gpu * c_gpu;
denom = fmax(fabs(denom), 1e-12) * (denom < 0 ? -1.0 : 1.0);
```

**影响**:
- 平板共存从完全崩塌恢复为可识别的气液分离（Tr=0.90 时 ρ_l=0.245, ρ_g=0.039）
- Laplace 定律、σ-解耦、接触角不受影响（这些验证本身就能正常工作）
- σ vs (1−6k₁) 线性关系保持 R²=0.9994

### 2.2 平板共存初始化改进（前一天延续）

**文件**: `lbm_mrt/solver/src/LBM.cu`, `init_all_scmp_gpu`

Mode=2 从单界面 tanh 改为 slab 几何（双界面，气-液-气），兼容周期边界条件：
```c
// Slab: liquid band centred at yc, half-width R0
double s_lo = 0.5*(1.0 + tanh(tfactor*(y - (yc-R0))/W));
double s_hi = 0.5*(1.0 + tanh(tfactor*((yc+R0) - y)/W));
rho = rho_g + (rho_l - rho_g) * s_lo * s_hi;
```
使用不等体积 slab（77% 液体，R0=98, yc=128）来稳定水平取向。

### 2.3 Zou/He 壁面 BC 仅对 mode=4 生效

**文件**: `lbm_mrt/solver/src/LBM.cu`, `zouhe_bottom_wall_gpu`

在核函数开头添加 mode 守卫：
```c
if (get_huang_init_mode() != 4) return;
```
防止 Zou/He 无滑移边界污染 mode=2（平板共存）和 mode=3（Poiseuille）。

### 2.4 Ghost ψ BC 扩展至顶部 ghost

**文件**: `lbm_mrt/solver/src/LBM.cu`, `update_ghost_psi_bc`

为 mode=2（平板共存）的顶部 ghost 节点 (y=NY-1) 添加 ψ 镜像：
```c
if (y == NY - 1) {
    psi[idx] = psi[findindex_scalar_gpu(x, NY-3)];
    return;
}
```

## §6 待解决

### 6.1 平板共存 — 低 Tr 气相失稳

**现象**: Tr ≤ 0.80 时气相密度 ρ_g 崩塌为 0 或与 ρ_l 相等。

**可能原因**:
- 低 Tr 下 CS EOS 气相密度过于稀疏（Tr=0.60 时 ρ_g=0.003），晶格无法维持
- 需通过 ε 调参来匹配力学稳定性条件 (Eq.61)
- 论文 Fig.4 使用 ε=1 和 ε=2（正 ε），可能产生更厚、更稳定的界面

**下一步**: 运行 ε=1,2 的平板共存扫参（CSV 已生成: `data/design_scmp_coexistence_eps_20260522.csv`）

### 6.2 σ vs (1−6k₁) 斜率异常

σ₀ ≈ 0.0684 远大于单个 Laplace 测量的 σ ≈ 0.00141。σ vs (1−6k₁) 图需要检查拟合方式——应使用各 ε 组的平均 σ 而非 σ_vs_1/R 过原点拟合。

### 6.3 Q_m 中 C 预乘松弛率

`compute_Q_huang_gpu` 将 Q_m 值预乘了松弛率 s_k（`C[1]=se*Qm1`），而论文 Eq.(5) 中 Q_m 项不应含松弛率因子。旧 MCMP 代码也有类似预乘（系数 1.5），但旧方案是 κ-based 而非 Huang 的 Q_m。此差异是否影响力学稳定性条件待验证。

### 6.4 分子力中混入体力

`compute_molecular_force_scmp` 将体力和分子力写入同一数组 (`F = -Gψ∇ψ + G·ρ`)。虽然 `compute_Q_huang_gpu` 在吸附力加入前调用，但体力（Gx, Gy）已混入 F 数组。对无体力验证（Gx=Gy=0）无影响，但对 Poiseuille 等有体力算例可能存在交叉污染。

## §8 关键经验

1. **`fabs(G)` vs `G`** — 论文中 Q_m 分母写的是 `|G|`，但由于代码压力张量用 `G`（带符号），为确保离散一致性，Q_m 分母也应用 `G`。这是用户的关键发现。
2. **周期性 BC 与平坦界面不兼容** — 单界面 tanh 在周期域中 ρ(0)≠ρ(NY−1)，系统通过崩塌为均匀或翻转 90° 来满足周期性。必须使用 slab（双界面）。
3. **旧代码的"正确"结果可能是假象** — 修复前共存曲线显示 0% 偏差，但这是因为 ρ 从未从 fin 更新。验证"通过"不代表代码正确。
